# Як додати чи оскаржити виконавця

## Додати

1. Знайди виконавця у Spotify. ID це частина посилання: `open.spotify.com/artist/`**`0fjbl13RhdZCsYBTLRDXGX`**
2. Додай рядок у `lists/blocklist.txt`: `0fjbl13RhdZCsYBTLRDXGX # Таїсія Повалій`
3. Якщо в виконавця кілька профілів на Spotify (латиницею й кирилицею, дублі), додай кожен.
4. Створи pull request і в описі вкажи **категорію та джерело**.

Автоматична перевірка скаже, якщо ID некоректний, дублюється або виконавець є в `allowlist.txt`.

## Критерії

| Категорія | Що потрібно в PR |
|---|---|
| Виконавець з Росії (громадянство, база, діяльність у РФ) | Посилання на Wikipedia/MusicBrainz/Wikidata або інше достовірне джерело |
| Українець чи інший виконавець, що живе або виступає в РФ чи публічно підтримує війну | Посилання на надійне журналістське джерело. Без джерела PR не приймається |
| Російськомовний виконавець без ясної країни | Лише якщо автор погоджується в обговоренні, один-два приклади треків |

Закордонних виконавців (не росіян), які виступали в Росії після 24.02.2022, додаємо в `lists/foreign.txt`, а не в blocklist: `ID # Ім'я | дата, місто | посилання на джерело`. Без підтвердженого виступу ПІСЛЯ 24.02.2022 (дата й посилання на новину, афішу чи квитки) запис не приймаємо. Користувач сам обирає, чи банити цей список.

Не додаємо: особисті образи, чутки без джерел, виконавців, які випускають українські пісні й не мають російського сліду (для них є `allowlist.txt`).

## Оскаржити чи прибрати

Відкрий issue «Оскаржити виконавця» з посиланням на Spotify і поясненням (наприклад, «з 2022 року лише українські пісні»). Якщо причина обґрунтована, виконавця переносимо в `allowlist.txt`.

## Код

Скрипт `src/ban.js` залежить від верстки веб-плеєра Spotify. Якщо перестав працювати, відкрий issue з описом (мова інтерфейсу, браузер, що саме не спрацювало). Перевірити списки локально: `python3 tools/build.py --check`. Тести частини скрипта, що не залежить від сторінки (`src/spotify.js`): `node --test tests/*.test.mjs`.
